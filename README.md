# Talabatk – Online Food Ordering Platform

## 1. Project Overview
Talabatk is a web-based food ordering platform designed to connect customers with restaurants and make the online food ordering process easier and more organized.

## 2. Technologies Used
- PHP
- Laravel 9
- Livewire 2.10
- MySQL

## 3. System Actors
- **Customer:** Browses restaurants and places food orders.
- **Restaurant:** Manages meals and receives customer orders.
- **Administrator:** Manages the platform and oversees its operations.
